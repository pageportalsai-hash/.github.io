# TRILLION RUN

A polished fictional-money bankroll game.

- Start with $100 in virtual money.
- Choose between three risk tables.
- Reach $1 trillion to complete the run.
- Hitting $0 ends the run and resets to $100.
- Best bankroll is saved locally in the browser.
- No real money, purchases, deposits, withdrawals, prizes, or cash-out.

Open `trillion-run/index.html` or serve the repository with GitHub Pages.
